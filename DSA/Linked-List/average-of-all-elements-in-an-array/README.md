## 📝 Problem Statement

Given an array **nums** of n integers, return Average of all Elements of given array.

### Example 1

<p>

**Input:** nums = [1, 2, 3, 4, 5]</p><p>

**Output:** 3</p><p>

**Explanation:** </p>(1+2+3+4+5) / 5 = 15 / 5 = 3

### Example 2

<p>

**Input:** nums = [5, 8, 11]</p><p>

**Output:** 8</p><p>

**Explanation:** </p>(5+8+11) / 3 = 24 / 3 = 8

### Constraints

- 1 <= n <= 100
- 1 <= nums[i] <= 100

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
